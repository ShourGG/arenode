# 上游建站兼容

CDNFly v6 要求数字形式的用户套餐 ID 在 JSON 中使用数字。数据库仍以 TEXT 保存兼容标识，客户端仅将安全整数范围内的规范数字字符串转换为数字，其余套餐 ID 保持原样。

建站 POST 出现断线或临时服务器错误时，不能直接认定建站失败。客户端会绕过资源缓存读取上游分页，按完整域名集合和客户分组核对是否已经创建成功：

- 找到匹配站点后返回其 ID，并失效缓存。
- 连续三次完整查询都确认缺失后，只受控重试一次建站 POST。
- 查询失败、未知响应结构、分页重复或超出查询上限时保留原始错误，不重放 POST。

客户端不会把上游缩小后的分页误认为完整清单。普通 POST 的请求层重试策略保持不变。该补偿机制依赖上游列表最终可见性，不替代上游支持的幂等键。

建站请求还支持服务端传入自定义 CC 规则、缓存策略、HTTP 版本及 WebSocket 设置。客户输入仍需经过应用层字段白名单和租户归属验证。

本改动没有数据库或环境变量变更，可直接回滚客户端代码。
