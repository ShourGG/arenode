# 代理来源与会话 IP

应用默认使用 TCP 连接的来源地址。经反向代理或 CDN 部署时，在 `TRUSTED_PROXY_CIDRS` 中配置实际可信代理的 IP/CIDR，支持逗号或空白分隔及 IPv4/IPv6。

```dotenv
# 示例地址；请替换为部署中实际的代理地址。
TRUSTED_PROXY_CIDRS=127.0.0.1/32,203.0.113.80/32
```

应用从 TCP 来源开始，按从右到左的顺序检查 `X-Forwarded-For`。只有当前一跳属于可信代理时才继续，遇到不可信来源或格式错误即停止。不单独信任 `X-Real-IP` 或 `CF-Connecting-IP`。各层代理需要正确追加连接来源；配置应包含完整的可信代理链，避免信任任意访客都能直接接入的地址范围。

会话、审计、登录、注册、邮件发送和验证码限流统一使用解析后的 IP。个人登录设备列表和管理员客户详情区分两个值：

- `ip`：创建会话时的登录 IP，后续访问不改写。
- `lastIp`（管理员详情中为 `last_ip`）：该设备最近一次有效会话请求的 IP，不表示实时在线状态。

升级时会自动执行 `ALTER TABLE sessions ADD COLUMN IF NOT EXISTS last_ip TEXT`。旧会话在下次有效请求后更新最近 IP，之前显示“待设备再次访问”，无需强制重新登录。回滚代码时可以保留这个可空字段；旧版本会忽略它。撤销 `TRUSTED_PROXY_CIDRS` 配置并重启即可恢复只使用 TCP 来源的行为。
